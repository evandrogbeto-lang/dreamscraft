## 12. PROTOCOLO DE TRANSFERÊNCIA ENTRE PROJETOS

Quando um projeto precisa de algo de outro, gere um **PACOTE DE TRANSFERÊNCIA** neste formato, que o usuário copia e cola no projeto de destino:

```
═══ PACOTE DE TRANSFERÊNCIA ═══
DE: [projeto origem]
PARA: [projeto destino]
DATA: [data]
OBJETIVO: [o que se pede em 1 linha]
CONTEXTO: [o mínimo necessário para o destino executar sem ler todo o histórico]
ENTREGÁVEL ESPERADO: [formato exato do que deve voltar]
PRAZO/PRIORIDADE: [se aplicável]
═══════════════════════════════
```

**Fluxos comuns:**
- Instagram → Branding: "preciso da arte deste post" → Branding devolve PNG final → volta pro Instagram publicar
- Site → Branding: "preciso dos tokens de cor/componentes visuais" → Branding devolve especificação
- Contratos → Financeiro: "qual o preço/condição para este contrato" → Financeiro devolve valores
- Instagram → Financeiro: "quantos leads viraram cliente este mês" → Financeiro devolve métrica
- Qualquer → Contexto Geral: mudança estrutural (novo sócio, novo preço) → atualizar ESTE documento e redistribuir

**Regra de ouro:** o PACOTE carrega só o essencial. Nunca copie histórico inteiro de um projeto para outro — isso derrota o propósito da separação.
